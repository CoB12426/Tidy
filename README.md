# Tidy

Tidy is a minimal Android home launcher.

## Download

Get the latest APK from the [Releases](https://github.com/CoB12426/Tidy/releases/latest) page.

1. Download `app-release.apk` (or the APK attached to the latest release) on your Android device.
2. Open it and allow installation from unknown sources if prompted.
3. Set Tidy as your default home app.

> The source code of Tidy is no longer published in this repository. This repository is used only for distributing release builds.
